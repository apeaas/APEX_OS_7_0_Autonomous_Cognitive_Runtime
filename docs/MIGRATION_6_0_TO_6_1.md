# Migración de APEX OS Genesis 6.0 a APEX OS 6.1

1. Cerrá APEX.
2. Conservá la carpeta 6.0 como respaldo.
3. Descomprimí 6.1 en una carpeta nueva.
4. No combines manualmente `assets`, `config` ni `index.html` entre versiones.
5. Serví la nueva carpeta desde el mismo navegador y, preferentemente, el mismo host/puerto local.
6. Abrí `index.html` y presioná `Ctrl + F5`.

Las claves anteriores de portfolio, bots, densidad y watchlist se conservan cuando el origen del navegador es el mismo. La memoria 6.1 comienza a construirse desde su primera apertura.
