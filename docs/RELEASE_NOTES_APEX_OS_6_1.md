# Release Notes — APEX OS 6.1

## Quantum Leap técnico
APEX incorpora una columna vertebral de eventos persistentes y memoria propia sin alterar el Living Cockpit de Genesis 6.0.

## Nuevo
- Core Event Bus con schema 1.0.0.
- IDs, secuencia, correlación, case ID, activo y checksum.
- Persistencia local de hasta 1.800 eventos.
- Memoria de decisiones, objeciones, auditorías, resultados y observaciones.
- Workspace visual de Event Stream y Persistent Memory.
- Filtros por tipo, agente y texto.
- Inspector de payload e integridad.
- Exportación JSON completa.
- Replay seguro por correlación, sin efectos secundarios.
- Historian conectado a la memoria propia.
- Chat capaz de recordar la última decisión persistida.
- Registro de aprobaciones, rechazos y vetos de Risk.
- Registro de aperturas y cierres paper.

## Preservado
- Genesis Living Cockpit.
- Binance REST/WebSocket.
- EMA, RSI, ATR y volumen.
- Thinking Engine, Case Engine y Fiscal.
- Governance y Constitución.
- Portfolio y ejecución paper.
- Autonomía máxima del 5%.

## Límites explícitos
- El almacenamiento actual es local al navegador.
- No existe todavía una base de datos remota.
- El aprendizaje no modifica estrategias por sí solo.
- Live trading continúa bloqueado.
