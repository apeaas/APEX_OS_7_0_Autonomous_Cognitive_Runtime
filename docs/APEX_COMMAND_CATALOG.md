# APEX 7 — Command Catalog

## Lectura y navegación

| Herramienta | Uso |
|---|---|
| `navigate_platform` | Abre Mission, Market, Thinking, Governance, Operations, Memory o Runtime. |
| `focus_asset` | Cambia el activo principal. |
| `refresh_market_reading` | Actualiza lectura cuantitativa. |
| `open_evidence` | Abre evidencia del activo. |
| `inspect_runtime` | Resume presupuesto, queue, planes, permisos o integraciones. |
| `query_system_memory` | Busca decisiones, objeciones, auditorías, outcomes y eventos. |

## Casos y planes

| Herramienta | Uso |
|---|---|
| `create_case` | Construye expediente con hipótesis y evidencia. |
| `create_plan` | Crea misión operativa o de research. |
| `manage_plan` | Activa, pausa, completa o cancela un plan. |

## PAPER execution

| Herramienta | Uso |
|---|---|
| `prepare_paper_trade` | Arma ticket sin ejecutar. |
| `execute_paper_trade` | Abre posición PAPER bajo validación. |
| `close_paper_position` | Cierra total o parcialmente. |
| `modify_paper_position` | Ajusta stop o target sin elevar riesgo inicial. |

## Plataforma y gobierno

| Herramienta | Uso |
|---|---|
| `set_agent_state` | Pausa o reactiva Sentinel, Spot Hunter o Sandbox. |
| `set_watchlist` | Agrega o quita activos. |
| `run_governance_audit` | Ejecuta autoauditoría. |
| `change_runtime_mode` | Cambia Observe/Copilot/Paper Auto/Suspended. |
| `update_runtime_config` | Ajusta parámetros dentro de locks. |
| `run_autonomous_cycle` | Fuerza un ciclo cognitivo. |
| `emergency_stop` | Suspende y cancela pendientes. |
| `resume_after_emergency` | Reanuda con protocolo humano. |
| `export_system_memory` | Exporta Event Bus y memoria. |
| `export_runtime_state` | Exporta runtime, planes, queue y auditoría. |

## Lenguaje natural sugerido

- “Ponete en Copilot.”
- “Mostrame cuánto presupuesto autónomo queda.”
- “Creá un plan swing de ETH y definí criterios de salida.”
- “Prepará un ticket PAPER, no lo ejecutes.”
- “Cerrá la mitad de la posición y protegé el resto.”
- “Explicame las últimas tres objeciones del Fiscal.”
- “Corré una autoauditoría y reducime autonomía si corresponde.”
- “Detené todo.”
