# APEX Thinking Architecture I

## Ciclo cognitivo
Observación -> hipótesis -> evidencia -> contraevidencia -> precedente -> deliberación -> decisión -> auditoría -> aprendizaje.

## Case Engine
Cada oportunidad crea un expediente con identidad, activo, horizonte, hipótesis, evidencia, contraevidencia, consenso, decisión propuesta y estado de autonomía.

## Prosecutor Agent
No busca oportunidades. Busca fallas: hipótesis alternativas, ausencia de falsabilidad, sobreajuste, evidencia débil, riesgo oculto y dependencia de datos incompletos.

## Historian Agent
Recupera escenarios comparables. La futura implementación deberá usar datos históricos reales, atributos de régimen, volatilidad, liquidez y contexto; no solo similitud visual de precios.

## Committee Deliberation
Los agentes emiten aprobación, objeción o veto. Risk y Governance tienen veto duro. Execution no interpreta: ejecuta únicamente una autorización válida.

## Estado de esta entrega
- Case Engine: interfaz y lógica local funcional.
- Fiscal: revisión adversarial funcional basada en reglas.
- Historiador: precedentes demostrativos, no base histórica real.
- Deliberación: trazable y visible.
- Live trading: bloqueado.
