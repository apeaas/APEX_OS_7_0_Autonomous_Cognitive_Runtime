# Release Notes — APEX OS Genesis 6.0

## Universal Stream of Success

Esta entrega reemplaza Quantum Rebirth y recompone Mission Control siguiendo el mockup validado por el usuario.

## Cambios principales

- Nuevo APEX Design System v1.
- Rack operativo de seis motores.
- Core reducido y equilibrado con el resto del cockpit.
- Mercado en formato radar compacto.
- Decisión convertida en instrumento, no artículo.
- Alertas visibles en la primera fila.
- Estrategias, posiciones y portfolio recuperan protagonismo.
- Comité, actividad, agentes y copiloto visibles sin invadir.
- Navegación lateral ampliada con lenguaje de sistema operativo.
- Chat y placeholder a 16 px.
- Responsive específico para 1366 × 768.
- Sin desbordamiento horizontal en 1366 y 1440.

## Correcciones

- Evidencia ya no falla si el usuario la abre antes de terminar la primera sincronización.
- Eliminado un posible bucle de actualización de la capa Genesis.
- Motores alineados: se neutralizaron offsets heredados de la disposición orbital.
- El Core Canvas mantiene movimiento entre frames.

## Preservado

No se removió la arquitectura lograda: Binance, indicadores, Case Engine, Fiscal, Historiador, Governance, Constitución, paper portfolio y techo autónomo del 5%.
