# Release Notes — APEX OS 6.2

## AI Command Runtime

- backend local sin dependencias;
- integración real con OpenAI Responses API;
- tool calling para comandar APEX;
- snapshot integral de plataforma;
- conversación con contexto y memoria reciente;
- fallback local explícito cuando falta configuración.

## Comando global

- chat principal actualizado;
- Command Palette con `Ctrl+K`;
- launcher flotante;
- comandos desde Mission Control;
- estado de IA en topbar.

## Voz

- dictado push-to-talk en español argentino;
- comandos “confirmo” y “cancelar”;
- síntesis de respuestas opcional.

## Herramientas

- navegación;
- foco por activo;
- lectura y evidencia;
- construcción de casos;
- tickets paper;
- ejecución paper con confirmación;
- cierres parciales o totales;
- modificación de stop/target;
- agentes;
- watchlist;
- Governance;
- exportación de memoria.

## Seguridad

- clave fuera del frontend;
- servidor enlazado a localhost;
- allowlist cerrada de herramientas;
- PAPER COMMAND desarmado al iniciar cada sesión;
- acciones sensibles con confirmación;
- Risk y Governance conservan veto;
- cuentas externas y live trading deshabilitados.
